- Предисловие -

Мини-книга описывает ключевые события мира трёх звёздных систем - в очень коротких эпизодах.

- Пролог -

Они ушли из старого мира тихо.
Без войн. Без сожалений. Без прощаний.
Три человека, три решения, три будущих мира.
Старую Федерацию они оставили позади — гниющую, коррумпированную, неспособную измениться.
Они не стали её спасать.
Они решили начать заново.
Теперь у каждого из них — своя планета.
Свои законы.
Своя версия справедливости.
Та история закончилась.
Эта — только начинается...
